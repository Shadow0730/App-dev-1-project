# Trek Management Application

This is a Flask-based Trek Management web application. It supports Admin, Trek Staff, and Trekker users with role-based dashboards.

## Requirements

- Python 3.x
- pip

## Install Required Libraries

Open a terminal in the project folder and run:

```bash
pip install flask flask-sqlalchemy
```

## Run the Application

From the project folder, run:

```bash
python app.py
```

After running the command, open this URL in your browser:

```text
http://127.0.0.1:5000/
```
